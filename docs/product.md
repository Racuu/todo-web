# 产品与交互

## 清单与导航

- 层级为组 → 清单 → 任务。组可选。没有清单时先建清单，再在清单内添加任务。首页优先打开此设备为当前仓库记住的清单，其次打开现有清单。
- “我的一天”“重要”“计划内”跨清单查看和编辑任务。新任务从所属清单创建，不设“所有任务”和默认“任务”入口。旧版未归类任务可从“待归类”找到并移入清单。

桌面打开任务后，详情约占窗口宽度的 44%。点击任务列表的空白处回到当前清单，点击侧栏空白处回到组与清单导航。手机在任务详情顶部固定“返回清单”，也可轻点左侧露出的空白边缘返回。打开清单抽屉后，可点右侧空白边缘收起。返回前完成本地编辑保存，保留原列表位置。较长的步骤名称会换行。

## 菜单与外观

- 品牌写作 To Doo，蓝白配色，标志用方正的勾。菜单项、快捷键和子菜单沿用统一字号。桌面支持右键，触屏可点对应的更多操作按钮。
- 组菜单支持重命名、组内新建清单、取消分组。取消分组后，原清单及其任务保留。
- 清单侧栏菜单支持重命名、移到首位、调整清单位置、移到其他组、从组中移除、复制和删除。同一组内可拖动清单左侧的三横线，也可点三横线按目标名次和相邻清单选择位置。未分组清单也可彼此排序。清单内右上角三点另有“排序依据”，用于排列其中的任务。复制为清单及其中未删除的任务分配新编号。删除会提示涉及的任务数量。
- “从组中移除”只改变清单归属。菜单不提供共享、打印、邮件发送、固定到开始或主题设置。
- 手机长按任务标题后上下拖动，电脑按住标题拖动。松手保存当前视图的顺序，计划内可在同一日期分组中拖动。清单如已选自动排序，可在“排序依据”切回“手动排序”。
- 任务菜单支持加入或移出“我的一天”、切换重要或完成状态、今天到期、明天到期、自选日期、移动到其他清单、删除。

## 任务与日期

- 详情按标题与完成/重要状态、步骤、“我的一天”、截止日期、重复、备注组织。长标题随详情宽度自动换行，编辑时随内容增高。步骤可逐项勾选。手机轻点步骤文字可编辑，长按文字可上下拖动，拖动时抑制文字选择，靠近详情顶部或底部会自动滚动。电脑支持鼠标拖动，键盘聚焦步骤文字后可按 Alt 加上下方向键移动。松手后的顺序随任务保存、同步和备份。手机备注支持全选、展开或收起，也可拖动底部横条调高或调低。点步骤右侧的“×”会弹出带步骤名称的确认框，确认才删除，取消会保留步骤。已完成任务在展开时加载对应行。详情不提供提醒、分配或附件。
- 截止日期预设为今天、明天、下周（下一个周一）和选择日期。以设备本地日历计算，覆盖跨月及跨年。
- 今日到期的未完成任务自动加入“我的一天”。详情、任务菜单和自选日期均适用。提前设好日期的待办也会在到期当天出现。当天手动移出后，刷新仍保留这个选择；再次选择“今天”或手动加入可恢复。今天到期的待办改到其他日期或清除截止日期后会自动移出“我的一天”，完成后会列在当天的“已完成”。
- “计划内”按截止日期分为先前、今天、明天、后天至今天后第六天的具体日期区间、稍后。无任务的日期分组隐藏，有任务的分组可展开或折叠。
- 重复任务支持每天、工作日、每周、每月、每年。验证完成动作时，同时检查本次完成状态和下一次任务。
